# What?

`# Inference` is an [[005 Process Notes may contain artifact sections in non journal headers|artifact section]] that records propositions and explanations about the underlying [[000 Term Process Note|process note]] context that exist independently of any changes that note introduces or plans to introduce.

`# Inference` can capture facts distilled from investigations about the underlying activity or the tools. It comes with a few different variants:
- as a `# Resolution` for note types which are resolved by an explanation or fact such as notes of type `investigation` and `issue`.
	- Expectations for how `# Resolution` is satisfied can be put under `# Objective`. Example: Some investigations and issues can only be resolved by explanations that make use of a program that reproduces some behavior of interest.
- as a `# Preconditions` for enumerating facts (and assumptions the note declares) which affect the operations in the note.

There is also notes with a dedicated type `inference` where such content can reside to facilitate reuse. They can be linked by other notes in their associated inference section and variants.

In contrast to `# Decision` artifact sections,

[[022 Decision artifact sections enumerate key facts about changes and commitments produced by the process note]]. So these can record post conditions, prescribe policy decisions, and so on.

In general, `# Inference`s should be descriptive or explanatory. `# Decision`s on the other hand can explain changes but also prescribe new policy decisions and then justifies them with an explanation.
