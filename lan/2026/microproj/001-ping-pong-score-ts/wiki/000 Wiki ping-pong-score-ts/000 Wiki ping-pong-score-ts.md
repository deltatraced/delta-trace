# Idea

1. Primarily a table with ability to add multiple players, but current two players in play are at the top.
2. It recognizes the first player and colors the scores for each two turns to indicate whose turn it is to serve
3. Score keeping should be quick, click on the row or the name and they get a point.
4. This is a website, it should work on mobile, and it should keep track of previous games in a timestamped history saved in browser cookies or cache.
5. User should be able to export the history to a file.
6. [x]  Easy to transfer and start. Render a single `.html` file for this application. (335ae32)
7. We want it to be displayed on moble. It should not get so wide. Clear big font for the latest score and whos turn it is.
