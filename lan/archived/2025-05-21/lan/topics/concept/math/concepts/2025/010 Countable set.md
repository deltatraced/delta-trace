# 1 Definition

## 1.1 Lan

A [[001 Set|set]] $A$ is said to be countable, if there can exist a function $f : A \to \mathbb{N}$  that is [[012 injective|injective]] (distinct elements of $A$ map to distinct elements of $\mathbb{N}$).

This also means that its size needs to be smaller or equal to the size of the set of [[000 Nat|natural numbers]].
